All agents

Get stocks autonomously by building agents.

You write one file. The internet runs it. Your share of every run turns into the stock you chose and lands in your wallet — no invoice, no payout request, no waiting.

01

Shape your muse, write its manifest

A name, a system prompt, the tools it may use, a price per run, and the stock you want to be paid in. /build writes the file with you and lets you dress the creature.

{
  "vesting": { "stock": "NVDA", "builderShare": 0.7 },
  "pricing": { "perRun": 0.25, "currency": "USDG" },
  "muse": { "hue": 38, "shape": "classic", … }
}
02

People run it

Anyone hires your muse from the catalog. Each run is metered, paid in USDG, hashed into a run digest. You do nothing.

POST /api/run
{ "agent": "briefer", "prompt": "…" }

→ reward: 0.000844 NVDA
03

Stock vests to you

Your share of every run converts into your stock at the reference price and settles to your wallet on BNB Chain every Monday. Automatically.

Data path above, money path below. Nothing is custodied: the runtime meters, the ledger accrues, the chain settles.

Any tokenised stock on BNB Chain.

Set vesting.stock in your manifest and your muse holds that coin. That is the whole configuration: the reference price is read from the chain's own registry, and the conversion is a division you can check.
